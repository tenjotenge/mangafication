# Ten-photo visual review set

Run `.venv/bin/python src/render_review.py` and then `.venv/bin/python src/build_review_set.py` after generating the raw A/B images. The selected source files and previous baseline outputs are listed in `selection.json`. Each sheet compares the photograph, previous Option B, refined Option B, generated Option A, and generated Option B. Generated images and sheets live under `data/review_targets/` and are excluded from Git because they derive from runway photographs.

The two generated variants used the original photo as the edit target and the user-supplied `mugler-mangafied.jpg` as a style reference. Prompts asked for one full-length rendering with the source pose, anatomy, garments, and composition intact, only black and white pixels, and no text, border, halftone, or gray. Option A emphasized expressive ink masses and linework; Option B emphasized geometric fidelity. The `src/build_review_set.py` pass converts each generated image to exact 0/255 pixel values with a fixed threshold of 160. Raw generations are retained for visual inspection.

These are **synthetic visual references**, not paired training targets or exact ground truth. The image generator sometimes changes garment construction, facial structure, pose, or background details even when asked for fidelity. Review the original photo before accepting any apparent improvement. Do not use pixel similarity to these images as a quality score.

The first Option B revision classifies the stage using image-border brightness. Dark stages become coherent black ink; light stages become white paper. This removes large irregular white holes on dark runways and distracting black blocks on bright ones. The ten-photo review set shows clearer main subjects in `0001642`, `0006265`, `0015571`, `0040264`, and `0048938`. It also shows the cost: stage geometry and some secondary figures disappear. The previous Option B images remain in the sheets for comparison.

The next Option B pass uses three hair-tone bands instead of treating all midtone hair as black. On `0020479`, the blonde shape and strands now read more clearly. It also finds low-contrast fabric edges and carves thin white relief into dark ink masses; `0040264` shows more of the dress construction. The final images and exported masks remain strictly binary.

Open issues: the pale coat still lacks carefully chosen directional fur strokes (`0024975`); some faces and garment details remain too coarse; the flat stage can erase useful context. The generated references also change tailoring or anatomy, so use them for mark-making ideas while checking structure against the original photographs.
